# GSRhino project rules

- GSRhino is an independent local Gaussian splat viewer and file-exchange plugin for Rhino.
- Keep documentation, code comments, UI, examples, metadata and release materials focused on GSRhino. Do not introduce sibling-product names, service-platform branding, cross-project lineage, inherited implementation narratives or implied product affiliations.
- Keep build/runtime dependencies and project references self-contained within this repository and its declared public dependencies. Do not require neighboring repositories, service accounts or API keys.
- Describe format interoperability through neutral, versioned schemas and behavior. Keep compatibility functionality independent of producer branding.
- Use CuriousArc and qrost for project attribution. Preserve required third-party license notices and accurate references to Rhino, public standards and declared dependencies.
- Before delivery, review tracked content and packaged text for independent project identity. Do not put excluded product names into tests, comments or these rules merely to describe this constraint.
- Keep English readme.md and Chinese readme.zh-CN.md consistent. Distinguish automated evidence from manual Rhino acceptance.
